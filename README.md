## 🚀 Featured projects

<details>
<summary><b>🧠 CodeMind</b> — Repository intelligence &amp; AI-assisted code repair</summary>
<br>

Imports a public GitHub repo, maps files, functions, imports and calls with **Tree-sitter**, then finds relevant code using **hybrid retrieval (BM25 + MiniLM + reciprocal-rank fusion + graph expansion)**. An LLM plans, diagnoses and patches; a **network-disabled Docker runner** compares baseline vs patched tests so only *verified* fixes are accepted.

`Python` `FastAPI` `React` `Groq API` `Tree-sitter` `SQLite` `Docker`
</details>

<details>
<summary><b>⚙️ ModelForge AI</b> — Automated ML pipeline platform</summary>
<br>

A **LangGraph** workflow that profiles a dataset, preprocesses it, compares models and gates approval with metric-based quality checks. Approved models are saved with Joblib and served by **FastAPI**, with **Pytest** tests and **Prometheus** monitoring.

`React` `FastAPI` `LangGraph` `Scikit-learn` `Docker` `Prometheus`
</details>

<details open>
<summary><b>🎤 ResumeFlow</b> — AI job search &amp; mock interview prep</summary>
<br>

A **full-stack MERN app**: matches a resume to jobs, highlights missing skills, tracks applications, and runs **text / audio / video mock interviews** (WebRTC) with structured AI feedback in a React dashboard.

`React` `Node.js` `Express` `MongoDB` `Groq API` `WebRTC`
</details>

<details>
<summary><b>🛡️ UPI Fraud Detection</b> — Three-service fraud prototype</summary>
<br>

Node.js API gateway + FastAPI ML scoring service + React dashboard, with JWT auth, role-based access, Redis caching and MongoDB analytics, all containerized with Docker. [View the repo →](https://github.com/shobhit2294/UPI-Fraud-Detection)

`Node.js` `FastAPI` `React` `MongoDB` `Redis` `Docker`
</details>
